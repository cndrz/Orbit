Help & Shortcuts
Navigation
1234Switch between Dashboard, Tasks, Data Viewer, Agent
?Open this help modal
General
Orbit is a local-first productivity app — everything stays on your machine
Sidebar buttons navigate between views; active view is highlighted
Click the gear icon for Settings (API key, theme, reset data)
All data persists automatically via SQLite — no save button needed
Tasks Panel
+Add a new task (header button opens a modal)
ⓘCreate a new category (header button opens a modal)
Click the circle to toggle a task done / undone
Click a category header to collapse / expand its tasks
Delete button appears on hover over any task or category
Add Task Modal
EnterSave the task (when focus is on the name field)
EnterAdd a tag (when focus is on the tag input)
Categories, priority, due date, and tags are all optional
Click New Category inside the modal to create a category on the fly
New Category Modal
Give your category a name and pick a color from the palette
EnterSave the category (when focus is on the name field)
Deleting a category moves its tasks to Uncategorized
Importing Data
Click Import in the panel header to load a CSV, XLSX, or XLS file
Or drag-and-drop a file onto the drop zone in the panel
Use the Import button again to replace the loaded dataset
Working with Data
Type in the Filter search bar to filter across all columns in real time
Click the × button to clear the current search
Horizontal and vertical scroll if the table is larger than the panel
Persistence
Imported data persists across sessions — stored locally in SQLite
Only one dataset is stored at a time; importing a new file replaces it
Clear all data (including imported files) via Settings → Clear all tasks and imported data
Chat Basics
EnterSend your message to the agent
Shift + EnterInsert a new line in the message box
The agent runs on Groq's llama-3.3-70b-versatile model
Context & Capabilities
Your task list is always included in every message — the agent knows your tasks
Toggle Include data from Data Viewer to also give the agent your imported table
Ask about task priorities, due dates, categories, or specific content
Ask questions about your imported data — summaries, filtering, analysis
Setup
Open Settings (Esc or sidebar gear icon) and enter your Groq API key
